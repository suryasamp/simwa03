SIMWA (Sistem Informasi Manajemen Warga) adalah aplikasi berbasis Spring MVC yang dirancang untuk membantu pengelolaan data warga, pembayaran iuran, serta pencatatan transaksi secara terintegrasi.
Aplikasi ini mendukung integrasi dengan Midtrans Payment Gateway untuk proses pembayaran online, serta menggunakan PostgreSQL sebagai basis data utama.

### 🔧 Fitur Utama<br>
- Manajemen data warga (CRUD)<br>
- Pembayaran iuran melalui Midtrans (Snap API)<br>
- Validasi transaksi menggunakan signature_key<br>
- Dashboard administrasi<br>
- Tampilan interaktif menggunakan jQuery dan AJAX<br>
- Struktur modular berbasis Spring MVC<br>

### 🧱 Teknologi yang Digunakan<br> 
- Backend: Java, Spring MVC, Spring Boot<br>
- Frontend: HTML, CSS, Bootstrap, jQuery<br>
- Database: PostgreSQL<br>
- Integrasi: Midtrans Payment Gateway<br>
- Version Control: Git & GitHub<br>

### 🚀 Tujuan<br>
Menyediakan sistem informasi yang efisien, transparan, dan mudah digunakan untuk pengelolaan iuran dan data warga di lingkungan masyarakat.
